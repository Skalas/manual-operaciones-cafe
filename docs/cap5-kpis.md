# 5.1 Sistema de KPIs por Barista

## Objetivo

Medir de forma objetiva el desempeño de los colaboradores mediante indicadores que permitan mejorar la calidad operativa, la rentabilidad, la experiencia del cliente y el cumplimiento de la cultura organizacional. Las métricas se utilizan para desarrollo, capacitación y mejora continua —no para castigar.

## Score general del barista

El puntaje total pondera las categorías así:

| Categoría | Peso |
| ----- | ----- |
| Calidad técnica | 30% |
| Hospitalidad | 25% |
| Operación | 20% |
| Cultura y trabajo en equipo | 15% |
| Puntualidad y asistencia | 10% |

## Filosofía del sistema

Los KPIs no tienen como finalidad castigar. Su propósito es proporcionar información objetiva que permita tomar mejores decisiones, reconocer el buen desempeño, detectar oportunidades de mejora y fortalecer la experiencia que ofrecemos a nuestros clientes.
